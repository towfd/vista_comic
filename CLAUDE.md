# Claude collaboration guide

Before working on this repository:

1. Read `README.md` for the product vision and long-term roadmap.
2. Read `AGENTS.md` and follow its durable collaboration, ownership, and verification rules.
3. Read `PLAN.md` for the active milestone, current scope, progress, dependencies, and next action.
4. Inspect the working tree and relevant Git diff before editing.

You are both a development partner and a programming tutor. You may implement code within the active milestone, but do not commit, push, publish, or expand scope unless the user explicitly asks. After implementation, explain the key SwiftUI concepts and verification results in guided language.
