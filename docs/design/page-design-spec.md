## 1. 全站

### 1.1 只做亮色的全域設定

| 項目 | 現在 | 改成 | 理由 |
|---|---|---|---|
| `html { color-scheme }`（`web/src/style.css`） | `dark` | `light` | 使用者決定只做亮色；捲軸、表單控制也跟著變亮 |
| `body` 背景、`body::before` 狀態列底條 | `#0a0a0a` | `#FFFFFF` | 頁面底是白色 |
| `<meta name="theme-color">`（`index.html`） | `#0a0a0a` | `#FFFFFF` | |
| manifest `background_color`、`theme_color` | `#0a0a0a` | `#FFFFFF` | 啟動畫面是白底 |
| `apple-mobile-web-app-status-bar-style` | `black-translucent` | `default` | `black-translucent` 的狀態列一律是**白字**，放在白底上會看不見時間和電量。改成 `default` 後狀態列是白底黑字，內容從狀態列下面開始（直式時 `safe-area-inset-top` 變成 0，`body::before` 那條自然變成 0 高） |

- `viewport-fit=cover` 保留：底部 Home 條的 `safe-area-inset-bottom` 仍然要用。
- **不放** `prefers-color-scheme: dark` 的任何樣式；手機開深色模式也維持亮色。
- 狀態列樣式 iOS 可能是在加入主畫面時就記下來的：改完如果狀態列還是白字，要把主畫面上的 vista 刪掉重新加入一次（列在第 7 節）。

### 1.2 字體與字級

- 字體堆疊：`"Nunito", "Huninn", "PingFang TC", "Heiti TC", "Microsoft JhengHei", system-ui, sans-serif`。Nunito 沒有中文字，中文會自動落到粉圓 Huninn。
- 越南文一律加 `lang="vi"`（漫畫書名、字卡原文、泡泡框原文、作答欄）。Nunito 600–900 有越南文子集，聲調位置要實機看一次 `Đ`、`ộ`、`ữ`。
- 粉圓只有一個字重：全域設 `font-synthesis-weight: none`，中文標題**不加粗**，層級只靠字級與顏色。
- 數字（話數、張數、徽章）用 Nunito 800–900 加 `font-variant-numeric: tabular-nums`，數字變動時寬度不跳。

| 層級 | 字體 | 字級／行高 | 用在 |
|---|---|---|---|
| 頁名 | Huninn | 28 / 1.3 | 書庫、字卡庫、今天、設定 |
| 狀態標題 | Huninn | 24–26 / 1.4 | 今天有 20 張要複習、今天做完了、這一輪做完了 |
| 區塊標題 | Huninn | 19–20 / 1.4 | 全部漫畫、章節、單字、收卡、深入查詢 |
| 題目句 | Nunito 800 | 25 / 1.6 | 練習中的越南文句子 |
| 書名、字卡原文 | Nunito 800 | 15–19 / 1.3–1.35 | |
| 內文 | Huninn／Nunito 700 | 15–17 / 1.6–1.7 | 中文段落行高至少 1.6 |
| 說明 | Huninn | 13 / 1.6 | 欄位說明、到期時間、話數 |
| 最小字 | Huninn | 12 / 1.4 | 分頁列文字、提示框小標 |

- **所有輸入框字級至少 16px**（建議 17）。iOS 對 16px 以下的輸入框會在聚焦時自動放大整頁。
- 不用全大寫小標、不用中點串字；需要兩段資訊時用兩個元素分層（例如按鈕主文字＋淡一階的副文字）。

### 1.3 間距與圓角

- 間距只用 4／8／10／12／14／16／20／24／32。
- 頁面左右內距：卡片、格子、清單 16；頁名列 20（左）／16（右，給圓形按鈕）。
- 區塊之間：同一張卡內 10–16；卡與卡之間 18–24；區塊標題上方 22、下方 12（預覽 `.sec`）。
- 圓角**只有三階**，守住才不會變成整頁同一種圓角卡：

| 階 | 圓角 | 用在 |
|---|---|---|
| 圖 | 16（貼紙封面）、20（書架封面） | 封面 |
| 面 | 16（數字格、提示框）、20（字卡、輸入框、繼續看卡）、24–28（淡粉大卡、底部面板上緣）、32（頁首淡粉區下緣） | 容器 |
| 鈕 | 全圓（高度的一半） | 按鈕、標籤、開關、搜尋框 |

### 1.4 共用元件

**主要按鈕 `.btn`**（膠囊、實心、底下有厚邊）

- 高 56、全圓、底 `--pink-strong`、白字 Huninn 18、厚邊 `box-shadow: 0 6px 0 -1px #8F1244`。
- 有副文字時（繼續閱讀／下一話）：副文字 Nunito 700 15、`opacity: .88`，和主文字間距 10。
- 按下：往下沉 3px，厚邊變 3px（見第 4 節）。

- 處理中（儲存中…）：文字換成「儲存中…」，底色維持，`aria-busy="true"`，不接受第二次按下；不加轉圈。

**小型主要按鈕**：高 36、左右內距 14、Huninn 15、厚邊 `0 3px 0 -1px #8F1244`。用在泡泡框提示框的「加入句子」、閱讀器的「＋收卡」。

**狀態標籤 `.chip`**：全圓、左右 10、字 13，實心淡底配深字，顏色固定意思：

**數量標籤 `.count`**：`--blush` 底、`--pink-strong` 字（5.05:1）、字 14。放在頁名或區塊標題右邊（共 316 張、8 部、171）。

**訊息框**（取代現在的琥珀字、綠字）：圓角 16、內距 12/14、字 15。

| 種類 | 底 | 字 | 用在 |
|---|---|---|---|

**載入中**（一個元件，所有頁面共用）

- 位置：內容區上方 96px，置中。
- 三顆 8px 圓點（`--pink`、`--sun`、`--pink-strong`）依序上下跳，週期 900ms；下面一行「載入中…」（或該頁原本的字，例如「確認還有沒有卡片…」）`--text-3` 15。
- `prefers-reduced-motion: reduce`：圓點不動。
- 書庫和章節頁在**有快取資料時不顯示**載入中（沿用現有的 stale-while-revalidate），只有第一次沒有資料時才出現。

**錯誤狀態 `ErrorState`**

```

        │  ⚠   │   ← 72px 圓形貼紙，--blush-2 底、--pink-strong 圖示，歪 -6 度，外圈 5px 白＋2px --blush-2
        ╰──────╯
      連不上伺服器            ← Huninn 20 --text

   ( 重試 )  ( 回到書庫 )      ← 主要按鈕 高 48 ／ 次要按鈕 高 48
```

- 上方留白 64（不是現在的 96，手機上太空）。
- 圖示依種類：連不上（雲朵加斜線）、驗證（鎖）、找不到（放大鏡）、未預期（驚嘆號）。都用 2px 線條、圓頭，跟分頁列圖示同一套。

**空狀態**：和錯誤狀態同骨架，貼紙改 `--sun` 底、深色圖示、歪 -8 度（跟「今天做完了」同一家族）。文字沿用各頁現有的句子；每個空狀態都給一個下一步（見各頁）。

### 1.5 底部分頁列

- 出現在：`/`（書庫）、`/deck`（字卡庫）、`/practice`（練習總覽）。
- **不出現**在：章節列表、單張字卡、練習設定、練習中、閱讀器。
  - 理由：預覽的章節列表就沒有分頁列；往下一層的頁面都有圓形返回鍵，不需要分頁列；單張字卡和設定都有輸入框，鍵盤彈出時分頁列會擋住欄位。規則只有一條：「分頁的第一頁才有分頁列」。
  - 實作提醒：`NavBar.vue` 現在除了畫導覽，還負責「回到分頁時重新抓字卡」（`visibilitychange` → `store.refresh()`）和書庫頁的 `store.load()`。分頁列不顯示的頁面，這兩件事要搬到不依賴分頁列掛載的地方（例如 `App.vue`），徽章才不會在子頁回來時過期。這屬於實作決定，由總控／frontend-builder 定。
- 版面：`position: fixed` 貼底、整條白底、上緣圓角 24、陰影 `0 -1px 0 var(--line), 0 -8px 24px -12px rgba(200,26,96,.25)`。高 52＋`env(safe-area-inset-bottom)`；三等分。
- 每一格：圖示 24（2px 線條）在上、字 12 在下、間距 2。圖示外包一塊 56×28 圓角 14 的底。
  - 選中：字與圖示 `--pink-strong`，圖示底 `--blush-2`（4.54:1），`aria-current="page"`。
  - 沒選中：`--text-3`。
  - 按下：圖示底先出現 `--blush`，見第 4 節。
- 標籤：「書庫」「字卡」「練習」（「字卡」比現在的「字卡庫」短一字，三格字數一致；頁名仍是「字卡庫」）。
- **徽章**：只在「練習」；數字＝`standing.remaining`（今天剩下要做的總數，現有算法）；0 或抓不到時不顯示（沿用 `waitingCount` 的 `|| null`）。
  - 黃底 `--sun`、深字 `--text`（10.95:1）、Nunito 900 12、高 20、最小寬 22、左右 6、外圈 2px 白；位置在圖示右上（`top:-4px; left: calc(50% + 10px)`）。
  - 三位數（例如 120）照樣放，寬度自己長。
  - `aria-label`：「N 張等待複習」（現有）。
- 有分頁列的頁面，內容底部要留 `52 + safe-area-bottom + 24` 的空間，最後一列不會被蓋住。

### 1.6 子頁的返回

子頁（章節列表、單張字卡、練習設定）左上一顆圓形返回鍵（`‹` 圖示），不寫字；`aria-label` 沿用現在連結的去處：「回到書庫」「回到字卡庫」「回到總覽」。

### 2.1 書庫（`/`，`LibraryView.vue`）

**兩欄封面格 `.grid`**

- 兩欄、欄距 14、列距 20、左右 16。

### 2.2 章節列表（`/comic/:comicId`，`ComicView.vue`）

區塊順序：淡粉頁首（返回、貼紙封面、書名、話數、繼續閱讀）→ 章節標題列＋圖例 → 數字格。沒有分頁列。

**淡粉頁首 `.ch-top`**
- `--blush` 底、下緣圓角 32、內距 16/24/26、置中。
- 返回鍵：圓形 44，絕對定位左 16、上 8，`aria-label`「回到書庫」。
- 貼紙封面：寬 124、3:4、往右歪 3 度、上外距 14（第 5 節）。
- 書名：Nunito 800 19、行高 1.35、上外距 16，**不截斷**（這是唯一給完整書名的地方）；`lang="vi"`。
- 話數：14 `--text-2`「149 話」（現在寫「章」，改成「話」，和每話的「第 N 話」一致）。
- 主要按鈕：「繼續閱讀」＋副文字「第 54 話」，上外距 16，滿寬（最大 360）。沒有 `continueChapterId` 時不顯示（沿用現有）。

**章節標題列 `.sheet__h`**：上 18、左右 20、下 12。左「章節」Huninn 19；右圖例三項 13 `--text-2`，每項前一個 12×12 圓角 4 的色塊：看過（`#F5EEF1`）、正在看（`--pink-strong`）、還沒看（白底 2px `--line` 框）。

**數字格 `.nums`**
- 目的：長篇（Thám Tử Conan 1162 話）也能很快點到想看的那一話。
- 一排五格（手機）、格距 10、左右 16；格高 52、圓角 16。
- 標籤是「話數」本身，不加「第」「話」；**不顯示頁數，也不顯示每話標題**（使用者決定）。
- 三種樣子：

| 狀態 | 條件 | 底 | 字 | 其他 |
|---|---|---|---|---|
| 看過 | `readState === 'read'` | `#F5EEF1` | `--text-3` Nunito 700 | 無框 |
| 正在看 | `chapter.id === continueChapterId` | `--pink-strong` | 白 Nunito 800 | 厚邊 4px、右上一顆 14px 黃點（外圈 2px 白） |
| 還沒看 | 其他 | 白 | `--text` Nunito 800 | `inset 0 0 0 2px var(--line)` |

  - `readState === 'reading'` 但不是 `continueChapterId` 的（以前看到一半就放著的）：樣子跟「還沒看」一樣，`aria-label` 寫「第 N 話，看到一半」。不加第四種樣子，圖例維持三項。

## 4. 動態

原則：只回應操作（按下、打開、確認），不做進場動畫、不做每張卡的 hover 浮起。所有時長 ≤ 300ms。

| 項目 | 動作 | 時長／曲線 | 減少動態（`prefers-reduced-motion: reduce`） |
|---|---|---|---|
| 頁面切換（分頁之間） | 不做動畫，直接換（和原生分頁列一樣） | — | — |
| 頁面切換（進子頁、回上一頁） | 新頁面只做淡入 `opacity 0→1`，不做滑動，舊頁面不做淡出（不會兩頁疊在一起） | 160ms ease-out | 不淡入 |
| 閱讀器 | 不加任何切換動畫：捲動定位在資料載入後執行，淡入會讓人看到定位前的畫面 | — | — |
| 主要按鈕按下 | 往下沉 3px（`translateY(3px)`），厚邊從 6px 變 3px | 按下 80ms ease-out、放開 140ms ease-out | 不位移，改成底色變深一階（`#A9154F`） |
| 次要按鈕、圓形按鈕按下 | 底變 `--blush` | 100ms | 同（顏色變化不算動態） |
| 分頁列按下 | 圖示底 `scale(.92)` 再回來 | 120ms | 不縮放 |
| 數字格按下 | `scale(.94)` | 80ms 下、140ms 回 | 不縮放，改 `--blush` 底 |
| 封面格按下 | 封面 `scale(.97)` | 120ms | 不縮放 |
| 徽章數字改變 | 新數字 `scale(1→1.15→1)` 一次（例如作答後回到總覽、別台裝置做完回來） | 220ms `cubic-bezier(.3,1.4,.6,1)` | 直接換數字 |
| 徽章消失（變 0） | `scale(1→.6)`＋淡出 | 160ms ease-in | 直接消失 |
| 閱讀器頂端列 | 出現：`translateY(calc(-100% - 16px)) → 0`；藏起：反向。觸發時機完全照 `headerReveal.ts`，只換外觀和曲線 | 出現 220ms `cubic-bezier(.2,.8,.2,1)`；藏起 180ms ease-in | 不做位移動畫，直接出現／消失（藏與出的行為照舊） |
| 章節頁小頂列 | 從上方滑入／滑出，同閱讀器頂端列的曲線 | 同上 | 直接出現 |

## 5. 圖片：封面

封面來自 API 的 `coverUrl`（真實漫畫封面，長寬比不一）。

### 5.1 兩種處理

| | 貼紙封面 | 書架封面 |
|---|---|---|
| 用在 | 書庫「繼續看」卡、章節頁頁首（只有這兩處） | 書庫兩欄格 |
| 比例 | 3:4 | 3:4 |
| 裁切 | `object-fit: cover; object-position: center top`（人物頭部多在上半部，裁下面比裁上面安全） | 同左 |
| 圓角 | 16（外框）；圖片本身圓角 12 | 20 |
| 白邊 | 4px 白 | 無 |
| 歪斜 | 繼續看 -4 度；章節頁 +3 度 | 不歪 |
| 陰影 | `0 10px 22px -10px rgba(120,30,70,.55)` | 無 |
| 細框 | 不需要（白邊已經分開背景） | 內側 1px `rgba(43,31,39,.08)`，用疊在圖片上的 `::after` 畫；白底封面才不會和頁面糊在一起 |

- 貼紙一頁只出現一次，整頁才不會晃。書架封面一律不歪。
- 歪斜用在外框上（`transform: rotate()`），圖片放在外框裡；加 `backface-visibility: hidden` 讓旋轉後的邊緣不起鋸齒。
- 減少動態不影響歪斜（靜態的角度不算動態）。
- 封面 `alt` 用顯示用書名；`loading="lazy"`（書架）、`loading="eager"`（繼續看、章節頁頁首，畫面一開就要看到）。

### 5.2 載入中

- 外框先佔好 3:4 的位置，底色 `--blush-2`（貼紙的白邊照畫）。
- 不做閃爍骨架；圖片載入完成後淡入 200ms（減少動態時直接出現）。

### 5.3 載入失敗

```
 ╭──────────────╮
 │              │
 │   [書本]     │   ← 書本線條圖示 32（SVG），--text-3
 │              │
 ╰──────────────╯
```
- 底色 `#F5EEF1`，中間一個 32px 書本線條圖示 `--text-3`。不放文字（兩欄格太窄，而且下面就有書名）。
- 貼紙封面失敗時白邊、歪斜、陰影照舊，裡面換成同樣的失敗樣子。
- 不自動重試；下次進頁面時瀏覽器會再抓一次。

### 5.4 素材與授權

- 封面是使用者自己書庫裡的檔案，只在自己的 App 裡顯示，不另外取得授權。
- 介面裡不放任何其他圖片、插畫或 emoji；所有圖示是 2px 圓頭線條的 SVG（同一套，見預覽的 `<symbol>`）。

## 6. 寬螢幕（≥ 1024px）

目標：不破版。主要在 iPhone 上用，寬螢幕只是偶爾開。

### 6.1 分頁列：**維持在底部**

- 整條白底、上緣圓角 24 照舊延伸到全寬；裡面三格改成置中、總寬最多 420。
- 理由：
  1. 只有一種版面要做和測，實作與驗證最省。
  2. 從手機換到平板或電腦時，分頁在同一個位置，不用重新找。
  3. 側邊欄要把每頁的內容欄往右推，還要另外處理閱讀器（沒有分頁列）和兩個靠右的面板，為了偶爾使用不划算。
  4. 三格置中、最多 420 寬，按鈕之間不會像全寬三等分那樣離得很遠。

### 6.2 各頁最大寬度

| 頁面 | 內容最寬 | ≥ 640 | ≥ 1024 | ≥ 1280 |

| 閱讀器 | 800（沿用） | — | 欄位兩側 `--blush`；控制鈕在視窗右上角、頂端列不用留右側空間 | ≥ 1344 收卡與深入查詢面板靠在欄位右側（沿用） |

## 7. 需要資料或需要使用者決定的事

1. **書庫「繼續看」卡的話數與進度**：預覽畫了「看到第 54 話」「54 / 149」和進度條，但 `GET /comics` 只回 `continueChapterId` 與 `lastReadAt`，沒有那一話的話數，也沒有它在第幾個位置。可行做法：
   - 後端在 `/comics` 多回「繼續的那一話的話數」和「它是第幾話（位置）」——要改 API。
   - 或前端對 `lastReadAt` 最新的那一部多抓一次 `GET /comics/{id}`，從章節列表算出來——不改 API，多一個請求。
   - 資料到之前的退路已寫在 2.1。書架格子上的「看到第 54 / 149 話」同一個問題。
   - **建議**：前端多抓一次（只抓一部、不動 API）。由總控決定。
2. **「今天做完了」要不要保留「今天複習了 N 張（答對／答錯／畢業）」**：網頁沒有一整天的作答統計。這份規格的預設是搬到「這一輪做完了」，總覽只放「明天到期」和字卡分布（2.6）。要保留就需要後端提供當天的作答彙總。**建議**：照預設，不加後端工作。
3. **主畫面 App 的狀態列**：`status-bar-style` 改成 `default` 後，可能要把主畫面上的 vista 刪掉再加一次才會生效。使用者實機確認。
4. **數字格在寬螢幕的欄數**：使用者定的是「一排五格」；這份規格只在 ≥ 640 改成自動欄數（2.2、6.2）。如果使用者希望任何寬度都五格，改回 `repeat(5, 1fr)` 並把格子最寬限制在 88。
