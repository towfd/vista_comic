## 既有限制（agent 必讀）

- 主要在 iPhone 主畫面 PWA 使用：要保留 safe-area 處理（`web/src/style.css`、`index.html` 的 `viewport-fit=cover`）。
- 閱讀器頂端列往下捲會藏、往上捲出現（`web/src/reader/headerReveal.ts`），使用者已確認喜歡，不要改掉行為。
- 漫畫原文是越南文（`lang="vi"`），字型要能正確顯示越南文的聲調符號。
- UI 驗證由使用者在實機做；不寫 XCUITest。

## 現況觀察（2026-11-14，r0 截圖：`docs/design/screenshots/r0/390-*.png`，取自部署版 192.168.0.45:8080）

1. 漫畫名稱顯示資料夾 slug（底線、無聲調），手機上被截斷。
2. 導覽在頂端、純文字，像網頁不像 App。
3. 配色只有黑灰加一個天藍，徽章與選中狀態沒有層次。
4. 章節列表每行都有「已讀」灰標籤，雜亂；目前進度不顯眼。
5. 字卡庫是純文字長列表；練習完成後整頁空白。

## 提給使用者的改版方向（尚未確認）

- 底部分頁列（書庫／字卡／練習，圖示 + 待複習徽章），閱讀器維持全螢幕。

- 自有主色（候選：App 圖示的粉／暖橘），圓角卡片、三層字級。
- 書庫：頂部「繼續看」大卡 + 進度條；章節頁：封面模糊背景頁首、已讀變暗、目前話數用主色、自動捲到目前位置。
- 字卡庫：越南文為主的小卡 + 階段彩色標籤；練習完成狀態顯示今日／明日數字與階段分布。
